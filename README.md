# Algoritma Simülasyonu — 9. Sınıf

9. sınıf **Bilişim Teknolojileri ve Yazılım** dersi için hazırlanmış, tarayıcıda
çalışan interaktif algoritma simülasyonudur. Tek bir HTML dosyasından ibarettir;
kurulum gerektirmez.

## İçerik

- **Giriş** — Algoritma nedir, özellikleri ve ifade şekilleri
- **Akış Şeması** — Semboller ve örnek akış şeması
- **Sıralama Algoritmaları** — Kabarcık, Seçmeli ve Eklemeli sıralamanın canlı görselleştirmesi
- **Arama Algoritmaları** — Doğrusal ve İkili arama görselleştirmesi
- **Karmaşıklık** — Büyük O (Big-O) notasyonu ve karşılaştırma tablosu
- **Mini Sınav** — Konuyu pekiştirmek için 6 soruluk interaktif test

## Çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterlidir. Herhangi bir bağımlılık,
kurulum veya sunucu gerektirmez.

```bash
# Linux/macOS
xdg-open index.html

# veya bir dosya sunucusu ile:
python3 -m http.server 8000
# Sonra tarayıcıda http://localhost:8000 adresini açın.
```
